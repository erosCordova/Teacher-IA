## Criterios de fidelidad

- Mantener la disposición visual aprobada.
- Conservar colores y apariencia equivalente.
- Usar los mismos apartados.
- Hacer funcional cada control.
- Mantener consistencia entre pantallas.
- No sustituirlo por un dashboard genérico.
- Evitar texto cortado y desbordamientos.
- Implementar temas claros y oscuros completos.

Las cifras y conversaciones de las maquetas son ejemplos visuales, no datos reales.
