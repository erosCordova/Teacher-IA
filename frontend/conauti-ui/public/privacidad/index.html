Política de privacidad

Explicamos qué información utiliza My Teacher IA, para qué se usa y cuáles son tus opciones de control.

Última actualización: 28 de octubre de 2026

1. Qué información tratamos

  • Cuenta: identificador de Google y correo verificado para las cuentas nuevas; nombre de usuario y contraseña protegida mediante hash en cuentas anteriores.
  • Actividad de aprendizaje: conversaciones, preguntas, respuestas, progreso, preferencias de estudio, evaluaciones y memoria educativa asociada a la cuenta.
  • Archivos: cuando adjuntas un documento, el sistema extrae un fragmento de texto para ayudar al tutor a responder; ese fragmento puede formar parte del historial de la conversación.
  • Imágenes y capturas: solo se envían para análisis cuando el usuario lo solicita. La aplicación no guarda el archivo visual original en la base de datos del tutor.
  • Datos técnicos: información necesaria para ejecutar el servicio, autenticar sesiones y diagnosticar fallos.

2. Para qué se utilizan

Se usan para mantener las sesiones, ofrecer conversaciones personalizadas, guardar el historial, generar ejercicios y dar seguimiento al aprendizaje, así como para proteger el acceso y resolver problemas de funcionamiento.

3. Servicios externos

My Teacher IA utiliza Google para verificar la identidad y Gemini para procesar consultas educativas y, cuando se solicita, contenido visual. La aplicación se aloja mediante Vercel y un servicio backend en Render, con almacenamiento de datos en PostgreSQL. Estos proveedores pueden procesar datos técnicos o contenidos necesarios para prestar sus funciones, conforme a sus propias políticas.

Evita enviar contraseñas, datos de terceros u otra información sensible a la inteligencia artificial.

4. Conservación y seguridad

Las conversaciones y datos de aprendizaje pueden mantenerse mientras la cuenta exista o hasta que se eliminen mediante las funciones disponibles o una solicitud de baja. Las sesiones tienen una duración configurada de siete días. Los registros técnicos y eventuales copias de respaldo pueden tener plazos distintos según la infraestructura utilizada.

Se utilizan autenticación, comprobación de permisos y controles de acceso; ningún sistema conectado a internet puede prometer seguridad absoluta.

5. Tus opciones y derechos

  • Desde la aplicación puedes solicitar la exportación de conversaciones y parte de tus datos de aprendizaje.
  • Puedes borrar conversaciones y algunos datos de memoria desde sus controles disponibles.
  • Las cuentas anteriores permiten iniciar el proceso de eliminación con su contraseña. Para cuentas registradas con Google, solicita la eliminación al correo de contacto indicado más abajo; no compartas tu contraseña ni tokens al solicitarla.
  • Puedes consultar o plantear una solicitud de corrección de datos mediante el contacto de privacidad.

6. Estudiantes menores de edad

El asistente está pensado para apoyar el estudio de secundaria. Si eres menor de edad, solicita autorización de tu madre, padre o tutor para utilizar la aplicación y evita compartir información personal de otras personas. La aplicación no sustituye la orientación de docentes y adultos responsables.

7. Contacto y modificaciones

Para solicitudes relacionadas con privacidad, escribe a eroscordova27@gmail.com. Podemos actualizar esta política cuando cambie el funcionamiento del servicio; en esta página se mostrará la fecha correspondiente.
