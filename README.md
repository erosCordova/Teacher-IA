# Asistente Educativo IA – CONAUTI

Sistema educativo con inteligencia artificial.

## Arquitectura

- Frontend: React, TypeScript y Vite.
- Backend: Python y FastAPI.
- Base de datos prevista: PostgreSQL.
- IA: asistente pedagógico multimodal.

## Diseño aprobado

- Chat claro.
- Chat oscuro.
- Historial y memoria.
- Voz y pantalla compartida.

## Iniciar el sistema

Ejecutar en dos terminales Git Bash:

```bash
bash iniciar-backend.sh
bash iniciar-frontend.sh
```

Frontend: http://127.0.0.1:5173

Backend: http://127.0.0.1:8000/api/health
